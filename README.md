# AI-Driven Product Research Analysis
## 手机外观调研全链路AI自动化分析体系

### 📖 项目简介
本项目构建了一套**开箱即用、高度标准化**的大模型数据分析Prompt工程体系，针对消费电子行业产品调研痛点，实现从原始问卷数据到业务洞察的全链路自动化处理。通过结构化指令设计，让ChatGPT、Claude等大模型能够精准执行复杂的统计分析任务，解决了传统人工分析效率低、易出错、维度单一、结果不可复现的核心问题。

> ✨ 核心价值：将原本需要3天的人工数据分析工作压缩至2小时完成，数据计算准确率提升至99%以上，支持10+人群标签与4大核心业务指标的多维度交叉分析。

---

### 🚀 核心功能
1. **标准化指标计算**：覆盖产品调研全流程核心指标
   - 4.1 有效样本量定义与全局规则
   - 4.2 外观NPS满意度指标计算
   - 4.3 购前吸引因素-外观维度分析
   - 4.4 购前放弃购买因素-外观维度分析
   - 4.5 购后体验-外观维度指标计算

2. **多维度交叉分析**：深度挖掘用户分层差异
   - 支持10类用户人群标签（性别、年龄、生活态度、消费偏好、城市级别等）
   - 单维度指标×人群标签交叉分析
   - 多维度全链路交叉分析（购前→购中→购后）

3. **智能统计检验**：自动完成专业统计分析
   - Pearson卡方独立性检验（分类变量差异）
   - 单因素方差分析（连续变量差异）
   - 自动判定显著性并标注异常情况
   - 理论频数不足、小样本等特殊情况处理

4. **统一输出格式**：生成标准化可直接使用的报告
   - 所有指标按本品/竞品分组独立输出
   - 统一的表格结构与数值精度
   - 自动标注异常与预警信息
   - 支持直接复制到PPT/Word报告

### 🛠️ 快速开始
#### 前置条件
- 拥有ChatGPT、Claude或其他支持长文本输入的大模型账号
- 准备好标准化的问卷调研数据（CSV/Excel格式）
- 明确本品与竞品的机型型号及对应题目编号

#### 使用步骤
1. **复制对应模块的Prompt**：根据分析需求，从`02-基础指标计算模块`或`03-高级交叉分析模块`中复制完整的指令内容
2. **配置个性化参数**：在指令开头补充以下信息：
   ```
   【执行参数】
   - 本品机型：XXX
   - 竞品机型：XXX
   - 本品预设样本量：600
   - 竞品预设样本量：450
   - 显著性水平：α=0.05
   ```
3. **上传数据并执行**：将配置好的Prompt和调研数据一起发送给大模型
4. **获取并验证结果**：大模型将按照标准格式输出分析结果，可直接用于业务报告

### 💡 项目亮点
1. **零代码门槛**：无需Python、SPSS等编程或统计软件基础，产品经理、市场人员可直接使用
2. **高度可扩展**：模块化设计，可轻松添加新的指标模块、人群标签或分析维度
3. **严格保真**：所有计算逻辑基于统计学标准，结果可复现、可验证
4. **业务导向**：所有分析任务均直接指向产品迭代和营销决策，输出结果可直接落地
5. **持续更新**：将根据实际使用反馈不断优化指令逻辑，增加更多行业场景支持
