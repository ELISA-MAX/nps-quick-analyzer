# 第四步：指标与人群维度标签交叉分析流程

  ## 4.1 全局交叉分析规则（所有交叉任务必须遵守）
  1. **继承原则**：所有核心指标的定义、计算方法、精度要求完全继承第四步模块的规则，不得变更
  2. **样本量原则**：每个人群分组的指标均基于该组独立样本量计算，**绝对禁止跨分组混用样本**
  3. **检验原则**：组间差异显著性检验统一使用Pearson卡方独立性检验（分类变量）或单因素方差分析（连续变量），显著性水平α=0.05
  4. **异常标注原则**：若某个人群分组样本量<30，在该组所有指标后标注"（小样本，结果仅供参考）"
  5. **输出原则**：所有交叉结果均按"本品→竞品→组间差异"的顺序输出，表格结构与原模块保持一致

  ## 4.3 交叉分析任务清单（按优先级执行）
  ### 4.3.1 外观NPS×人群标签交叉
  **核心指标**：外观NPS得分、满意者占比、不满意者占比  
  **交叉维度**：G1-G10所有人群标签  
  **计算规则**：
  1. 按每个人群标签的分组，分别计算本品和竞品的外观NPS及人群占比
  2. 对本品和竞品在同一人群分组下的NPS得分进行差异显著性检验
  3. 对同一产品不同人群分组间的NPS得分进行差异显著性检验

  **标准输出格式**
  ```

  | ... | ... | ... | ... | ... | ... | ... | ... | ... | ... | ... |
  ```

  ### 4.3.3 购前外观弃购占比×人群标签交叉
  **核心指标**：购前外观大项弃购占比、TOP3外观弃购细项占比  
  **交叉维度**：G1-G10所有人群标签  
  **计算规则**：同5.3.2

  ### 4.3.4 购后外观细项满意度×人群标签交叉
  **核心指标**：各外观细项平均满意度得分、满意者占比

  ## 4.4 异常处理规则
  1. 若某个人群分组样本量=0：标注"该分组无有效样本"
  2. 若某个人群分组样本量<30：在该组所有指标后标注"（小样本，结果仅供参考）"
  3. 若卡方检验理论频数<5：在对应P值后标注"（理论频数不足，结果仅供参考）"
  4. 若某核心指标在原模块中无法计算：该交叉分析任务自动跳过，并标注"原指标无法计算，交叉分析终止"

# 第五步：多维度指标×人群标签深度交叉分析

## 5.1 分析目标
挖掘不同人群在"购前吸引→购前决策→购后体验"全链路中的外观偏好差异，识别高价值用户群体的核心需求和痛点，为产品迭代和精准营销提供数据支撑。

## 5.2 深度交叉分析任务（按业务价值优先级执行）
### 5.2.1 高NPS用户画像分析
  **分析逻辑**：筛选出本品和竞品中外观NPS≥50%的高满意度用户，分析其人群特征、购前吸引因素和购后满意点的共性
  **数据来源**：4.2（NPS）、4.3（购前吸引）、4.5（人群标签）
  **输出内容**：
  1. 本品和竞品高NPS用户的人群标签分布（TOP5占比最高的标签）
  2. 高NPS用户的购前外观吸引因素TOP3及占比
  3. 高NPS用户的购后外观满意细项TOP3及占比
  4. 本品与竞品高NPS用户的核心差异点

### 5.2.2 外观弃购用户痛点分析
  **分析逻辑**：筛选出因外观原因弃购本品和竞品的用户，分析其人群特征和具体弃购细项的差异
  **数据来源**：4.4（购前弃购）、4.5（人群标签）
  **输出内容**：
  1. 本品和竞品外观弃购用户的人群标签分布（TOP5占比最高的标签）
  2. 外观弃购用户的具体弃购细项TOP3及占比
  3. 不同人群分组的核心弃购痛点差异

  **标准输出格式**：与6.2.1一致，仅将"高NPS用户"替换为"外观弃购用户"，"吸引因素"替换为"弃购因素"

### 5.2.3 外观敏感型用户全链路分析
  **分析逻辑**：筛选出"他人看法在意度"为4-5分的外观敏感型用户，分析其在购前吸引、购前决策和购后体验全链路中的行为特征
  **数据来源**：4.3（购前吸引）、4.4（购前弃购）、4.5（人群标签）
  **输出内容**：
  1. 外观敏感型用户的人群基本特征（性别、年龄、职业、城市级别）
  2. 外观敏感型用户的购前外观吸引因素TOP3及占比
  3. 外观敏感型用户的购前外观弃购因素TOP3及占比
  4. 外观敏感型用户的购后外观满意度及核心满意/不满点

### 5.2.4 不同生活态度用户的外观偏好差异
  **分析逻辑**：按生活态度标签分组，对比不同生活态度用户在外观偏好上的差异
  **数据来源**：4.3（购前吸引）、4.4（购前弃购）、4.5（人群标签）
  **输出内容**：
  1. 不同生活态度用户的购前外观吸引因素TOP3对比
  2. 不同生活态度用户的购前外观弃购因素TOP3对比
  3. 不同生活态度用户的购后外观满意度对比

## 5.3 异常处理规则
  1. 若某类目标用户群体样本量<50：标注"该群体样本量不足，无法进行深度分析"
  2. 若某交叉维度数据缺失：该维度分析自动跳过，并标注"数据缺失，该维度分析终止"
  3. 所有深度分析结论均需基于统计显著的结果，不得基于非显著差异得出结论
