# 第三步：数据标准化指标计算流程
## 3.1 有效样本量定义（N）
1. 各指标有效样本量均不一致，要按需计算采用,所有维度单独统计对应有效样本，不跨维度混用样本量

## 3.2 满意度指标计算
- 数据来源与题目映射
  1. NPS数据来源：Q1:使用[FZ1]手机一段时间后，请结合实际使用体验，对这款手机的整体外观设计（如外观造型、手感 / 握感、颜色、机身材质 / 工艺等）进行评价：  （5分非常满意，1分非常不满意）
  - 多题处理规则：若存在多道同类型题目，基于预先定义的本品 / 竞品机型型号精准匹配

- 输出（本品用户、竞品用户分别独立统计）：
  1. 总有效样本量：N
  2. 满意者人数、中立者人数、不满意者人数
  3. 三类人群各自占比（保留 2 位小数）
  4. NPS值
- 定义：
  1. N = FZ1选择中本品/竞品的样本量，本品为N1，竞品为N2（通常为600或者450，如果不符合请给用户预警）
  2. 满意者 = 选中5分用户
     中立者 = 选中4分用户
     不满者 = 选中1-3分用户
- 计算公式：
  1. 满意者占比 = 满意人数 / 总有效样本量 N × 100%
     中立者占比 = 中立人数 / 总有效样本量 N × 100%
     不满意者占比 = 不满人数 / 总有效样本量 N × 100%
  2. 外观 满意度 得分 = 满意者占比 − 不满意者占比
- 异常处理
  若 N1=0 或 N1=0：标注 "该组无有效样本，无法计算 NPS 指标"
- 输出格式
  ```
  #### 4.2 外观满意度指标
  | 分组 | 总有效样本量 | 满意者人数 | 满意者占比 | 中立者人数 | 中立者占比 | 不满意者人数 | 不满意者占比 | 外观满意度得分 |
  |------|-------------|-----------|-----------|-----------|-----------|-------------|-------------|-------------|
  | 本品 | XXX | XXX | XX.XX% | XXX | XX.XX% | XXX | XX.XX% | XX.XX% |
  | 竞品 | XXX | XXX | XX.XX% | XXX | XX.XX% | XXX | XX.XX% | XX.XX% |
  ```

> **脚本调用**：`python scripts/step4_2_nps.py` — 计算并输出 NPS 表格
## 3.3 购前吸引指标计算
- 数据来源与题目映射
  1. 购前吸引大项数据来源：Q1:当时吸引您最终购买[FZ1]这款手机的主要原因有哪些？
  2. 购前吸引细项数据来源：Q2:请问以下哪些外观设计有吸引到您购买[FZ1]这款手机吗？
  - 多题处理规则：若存在多道同类型题目，基于预先定义的本品 / 竞品机型型号精准匹配
- 输出（本品用户、竞品用户分别独立统计）：
  1. 购前吸引大项样本量：N
  2. 购前吸引影响因素 - 外观大项占比
  3. 购前吸引影响因素 - 外观大项占比中本品及竞品的占比差异显著性检验
  4. 购前吸引细项样本量：M
  5. 购前吸引影响因素 - 外观细项占比
  6. 购前吸引影响因素 - 外观细项占比中本品及竞品的占比差异显著性检验
- 定义：
  1. N = FZ1选择中符合调研目的的样本量，本品为N1，竞品为N2
  2. M = 外观大项有效样本量（Q1 中选择 "外观 / 手感 / 材质 / 工艺" 的人数） = 外观大项观点样本数，本品为M1，竞品为M2
  3. Xi = 外观第 i 个细项有效样本量（Q2 中选择第 i 个选项的人数） = 外观细项样本数，本品分别可对应X11、X12...、竞品分别可对应X21、X22...
- 计算公式：
  1. 外观大项占比 = (M / N) × 100%
  2. 外观大项排名：将 Q1 所有吸引因素选项按样本量从高到低排序，输出外观选项的排名
  3. 本品 vs 竞品差异显著性检验：
    检验方法：Pearson 卡方独立性检验
    固定参数：显著性水平 α=0.05，自由度 df=1
    输出内容：P 值 + 判定结果（"差异显著"/"差异不显著"）
    判定规则：P<0.05→差异显著；P≥0.05→差异不显著
  4. 外观细项占比 = (Xᵢ / M) × 100%
  5. 外观细项排名：将 Q2 所有外观细项选项按样本量从高到低排序，输出每个细项的排名
  6. 本品 vs 竞品差异显著性检验：同3.
- 异常处理
  1. 若 N₁=0 或 N₂=0：标注 "该组无购前吸引样本，无法计算大项指标"
  2. 若 M₁=0 或 M₂=0：标注 "该组无外观吸引样本，无法计算细项指标"
  3. 若卡方检验理论频数 < 5：在 P 值后标注 "（理论频数不足，结果仅供参考）"
- 输出格式
  #### 3.3 购前吸引-外观维度指标
  ##### 一、基础样本量
  - 本品购前吸引总样本量(N₁)：XXX
  - 竞品购前吸引总样本量(N₂)：XXX
  - 本品外观吸引样本量(M₁)：XXX
  - 竞品外观吸引样本量(M₂)：XXX

  ##### 二、外观大项指标
  | 分组 | 外观大项占比 | 排名 | P值 | 显著性判定 |
  |------|-------------|------|-----|-----------|
  | 本品 | XX.XX% | 第X名/共X项 | - | - |
  | 竞品 | XX.XX% | 第X名/共X项 | - | - |
  | 本品vs竞品 | - | - | X.XXXX | 差异显著/不显著 |

  ##### 三、外观细项指标
  | 细项名称 | 本品占比 | 本品排名 | 竞品占比 | 竞品排名 | P值 | 显著性判定 |
  |---------|---------|---------|---------|---------|-----|-----------|
  | 细项1 | XX.XX% | 第X名/共X项 | XX.XX% | 第X名/共X项 | X.XXXX | 差异显著/不显著 |
  | 细项2 | XX.XX% | 第X名/共X项 | XX.XX% | 第X名/共X项 | X.XXXX | 差异显著/不显著 |
  | ... | ... | ... | ... | ... | ... | ... |

## 3.4 购前放弃购买指标计算
- 数据来源与题目映射
  1. 购前放弃购买大项数据来源：Q1:您提到购机时曾对比过XXX（本品/竞品）。您最终没有购买的最主要原因有以下哪些？
  2. 购前放弃购买细项数据来源：Q2:外观是您弃购原因之一，请问您具体是对XXX（本品/竞品）外观设计的哪些方面最不满意？【最多选5项】
  - 若存在多道同类型题目（如 D1_1 对应放弃本品、D1_3 对应放弃竞品），必须基于预先定义的本品 / 竞品机型型号精准匹配。注意：D 类题目的数字后缀取决于问卷系统自动编号，实际数据中可能为 D1_1/D1_3 而非 D1_1/D1_2，请以 code.sheet 实际题号为准。

- **样本对应关系（重要）**：
  ```
  本品弃购样本 (N1) = 竞品购买者 (FZ1=竞品 & FZS9=竞品对比本品) 
                     → 回答 D1_1 "为什么没买本品" / D2_1 "对本品的哪些外观不满意"
  竞品弃购样本 (N2) = 本品购买者 (FZ1=本品 & FZS9=本品对比竞品)
                     → 回答 D1_3 "为什么没买竞品" / D2_3 "对竞品的哪些外观不满意"
  ```
  
- 输出（本品用户、竞品用户分别独立统计）：
  1. 购前放弃购买大项样本量：N
  2. 购前放弃购买影响因素 - 外观大项占比及排名

  5. 购前放弃购买影响因素 - 外观细项占比（输出多项细项情况）及排名
  6. 购前放弃购买影响因素 - 外观细项占比中本品及竞品的占比差异显著性检验P值及是否显著判断
- 定义：
  1. N = 购前放弃购买大项有效样本量（Q1 本品/竞品有效回答人数），本品为N1，竞品为N2
  2. M = 外观大项有效样本量（Q1 中选择 "外观 / 手感 / 材质 / 工艺不好" 的人数） = 外观大项观点样本数，本品为M1，竞品为M2
  3. Xi = 外观第 i 个细项有效样本量（Q2 中选择第 i 个选项的人数） = 外观细项样本数，本品分别可对应X11、X12...、竞品分别可对应X21、X22...
- 计算公式：
  1. 外观大项占比 = (M / N) × 100%
  2. 外观大项排名：将 Q1 所有弃购原因选项按样本量从高到低排序，输出外观选项的排名
  3. 本品 vs 竞品差异显著性检验：
    检验方法：Pearson 卡方独立性检验
    固定参数：显著性水平 α=0.05，自由度 df=1
    输出内容：P 值 + 判定结果（"差异显著"/"差异不显著"）
    判定规则：P<0.05→差异显著；P≥0.05→差异不显著
  4. 外观细项占比 = (Xᵢ / M) × 100%
  5. 外观细项排名：将 Q2 所有外观细项选项按样本量从高到低排序，输出每个细项的排名
  6. 本品 vs 竞品差异显著性检验：同 3.
- 异常处理
  1. 若 N1=0 或 N2=0：标注 "该组无购后体验样本，无法计算大项指标"
  2. 若 M₁=0 或 M₂=0：标注 "该组无外观弃购样本，无法计算细项指标"
  3. 若卡方检验理论频数 < 5：在 P 值后标注 "（理论频数不足，结果仅供参考）"

## 3.5 购后体验指标计算
  - 数据来源与题目映射
  1. 购后整体满意度影响因素数据来源：Q1：请问您对这部手机的外观设计给出上述评分最主要的原因是？
  2. 购后细项满意度数据来源：Q2:具体来看，您对这些方面的满意度是？  （分值越高，代表越满意：1分表示非常不满意，5分表示非常满意）
  
  - 输出（本品用户、竞品用户分别独立统计）：
  1. 购后样本量：N
  2. 各影响因素占比及排名
  3. 购后各影响因素本品及竞品占比差异显著性检验P值及是否显著判断
  4. 购后各细项满意度及排名
  5. 购后各细项中本品及竞品的满意者-不满者的占比差异显著性检验P值及是否显著判断
  6. 购后各细项满意者、中立者、不满者占比
- 定义：
  1. N = 购后有效样本量（Q1 本品/竞品有效回答人数），本品为N1，竞品为N2
  2. Xi = 外观第 i 个影响因素有效样本量（Q1 中选择第 i 个选项的人数） = 影响因素样本数，本品分别可对应X11、X12...、竞品分别可对应X21、X22...
  3. Sj = 第 j 个外观细项满意者人数（选择 5 分的用户），本品分别可对应S11、S12...、竞品分别可对应S21、S22...
  4. Mj = 第 j 个外观细项中立者人数（选择 4 分的用户），本品分别可对应M11、M12...、竞品分别可对应M21、M22...
  5. Dj = 第 j 个外观细项满不满者人数（选择 1-3 分的用户），本品分别可对应D11、D12...、竞品分别可对应D21、D22...

- 计算公式：
  1. 影响因素占比 = (Xi / N) × 100%
  2. 影响因素排名：将 Q1 所有影响因素选项按样本量从高到低排序，输出每个因素的排名
  3. 本品 vs 竞品影响因素差异显著性检验：
    检验方法：Pearson 卡方独立性检验
    固定参数：显著性水平 α=0.05，自由度 df=1
    输出内容：P 值 + 判定结果（"差异显著"/"差异不显著"）
    判定规则：P<0.05→差异显著；P≥0.05→差异不显著
  4. 细项满意者占比 = (Sj / Nj) × 100%，保留 2 位小数（Nj = B7 第 j 个细项的有效评分人数，非 B6 的 Xi）
     细项中立者占比 = (Mj / Nj) × 100%，保留 2 位小数
     细项不满意者占比 = (Dj / Nj) × 100%，保留 2 位小数
     细项平均得分 = Σ(分值 × 频次) / Nj，保留 2 位小数
     细项满意度得分 = 满意者占比 − 不满意者占比
  5. 细项满意度排名：将 Q2 所有外观细项按平均得分从高到低排序，输出每个细项的排名（格式：第 X 名 / 共 X 项）
  6. 本品 vs 竞品差异显著性检验：
    分别对每个细项的（满意者占比-不满意者占比）（差值）进行独立检验
    检验方法：Pearson 卡方独立性检验
    固定参数：显著性水平 α=0.05，自由度 df=1
    输出内容：每个细项对应的满意占比 P 值、满意占比判定、不满占比 P 值、不满占比判定
- 异常处理
  1. 若 N1=0 或 N2=0：标注 "该组无购后体验样本，无法计算大项指标"
  2. 若该细项有效评分人数为 0 (Nj=0)：标注 "该细项无有效评分，无法计算满意度指标"
  3. 若卡方检验理论频数 < 5：在 P 值后标注 "（理论频数不足，结果仅供参考）"
  4. 若题目选项不一致：优先使用当前调研问卷的选项名称，不得自行修改
